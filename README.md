## Windows 独立服务器到底是什么——谁才真正需要它

它是一台单租户物理机，直接在硬件上运行 Windows Server（没有虚拟机管理程序层，也没有其他租户），并可通过 RDP 获得完整的 Administrator 权限。每个物理核心都归您所有，这就是为什么对许可敏感的工作负载最终会落在这类机器上。

真正需要用到它的工作负载非常具体：

- **IIS 上的传统 ASP.NET 和 .NET Framework 应用。** 这些应用只能在 Windows 上运行。现代 .NET 在 Linux 上运行良好，因此在支付 Windows 税之前请务必确认。
- **高负载的 Microsoft SQL Server。** 数据库需要独占磁盘和内存，而虚拟邻居无法占用这些资源。请注意，SQL Server 是单独授权的，且通常是账单中金额较大的一项（更多内容见下文）。
- **面向团队的远程桌面服务**，或仅提供 Windows 客户端的业务线应用。
- **仅限 Windows 的游戏服务器**，稳定的响应速度很重要，因为中间没有虚拟机管理程序。
- **仅限 Windows 的交易平台、网桥和插件。**

如果您的应用在 Linux 上运行良好，就不要购买 Windows。一家美国主机商的 Windows 页面上说得非常直白：每月 50 美元的闲置许可证就是每年白白浪费 600 美元。这是整篇文章中最有价值的建议。

## 许可证才是真正的价格——以下是计算方法

Windows Server 按**物理核心**授权，每个处理器至少需要 8 个核心许可，每台服务器至少需要 16 个。任何总核心数在 16 个或以下的机器都支付相同的许可底线；超过这个数量，每个核心都要单独计费。版本决定了您可以在其上运行什么。

- **Standard（标准版）**授予每个完全授权的服务器两个操作系统环境——实际上是主机加上两个 Windows VM，或者如果主机仅运行 Hyper-V 角色，则可以运行两个 VM。在同一核心上叠加第二套核心许可可再增加两个 VM。
- **Datacenter（数据中心版）**允许在授权核心上运行无限数量的 Windows VM，一旦您在一台主机上运行大约 8 到 10 个 VM，它就变得非常划算。
- 在 GigeNet 目前的订购表中，这相当于 **Standard 版每月 50 美元，Datacenter 版每月 300 美元**。

然后是访问权。当您自带许可证（BYOL）在专用硬件上运行时，Microsoft 要求每个用户或设备拥有一个基础 CAL，如果运行远程桌面会话主机，还需要额外的 RDS CAL。当您通过服务商的 SPLA 租用时，这些是服务商需要解决的麻烦——您只需支付每月的许可证行项目费用，无需管理任何 Windows Server CAL。

关于 BYOL 的一点警告：这些权利适用于完全专用的单租户硬件，依据是 Microsoft 的外包软件管理权和灵活虚拟化权益。Windows Server 本身不在经典的“通过软件保障的许可移动权”（License Mobility through Software Assurance）覆盖范围内，因此请在订购前与您的经销商确认您的许可证状态。

## 在做其他任何事情之前，先锁定 RDP

在 TCP 3389 上对整个互联网开放的 RDP 端点是 Windows 服务器上受攻击最多的单一界面。针对 3389 的自动密码喷洒和暴力破解是持续不断的，新配置的服务器通常在数小时内就会受到扫描。

基本清单：

1. 配置防火墙，仅允许您自己的 IP 地址访问 3389，或者使用 VPN/跳转主机前置该端口。
2. 保持开启网络级身份验证（Network Level Authentication）。
3. 设置账户锁定策略，例如在连续 5 次失败尝试后锁定。
4. 为管理员账户设置长且唯一的密码——并确保每个人使用独立的账户。
5. 如果必须公开访问，请将其置于 RD 网关之后，而不是直接暴露原始的 3389 端口。

这些工作只需五分钟，却能让您的服务器避免 99% 的垃圾流量。请在安装第一个应用之前完成这些设置。

对于带有桌面体验的安装，Microsoft 自己的最低配置是 2 GB，但在实际使用中，4 GB 才是舒适的底线，1 GB 仅适用于单个无头微型角色。这就是为什么 RackNerd 的 1 GB 方案更适合作为单一的轻量级作业，而不是主服务器——大多数人应该从 2 到 4 GB 开始。

**通过 SPLA 租用时还需要购买 CAL 吗？** 不需要——服务商负责处理 CAL 相关事宜，您只需支付每月的许可证行项目费用。在拥有自带 Windows Server 许可证的专用硬件上，您需要每个用户或设备一个基础 CAL，如果运行远程桌面会话主机，还需要额外的 RDS CAL。

**我可以安装自己的 Windows Server 许可证吗？** 在完全专用的单租户硬件上通常可以，这依据的是 Microsoft 的外包软件管理权和灵活虚拟化权益。通过软件保障的许可移动权不涵盖 Windows Server 本身，因此请先确认您许可证的 SA 或订阅状态——Contabo 是接受在独立服务器上 BYOL 的服务商之一。
